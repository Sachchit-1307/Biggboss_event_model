BIGG BOSS HOUSE COMMAND CENTER

Open index.html to start.

Pages:
- index.html: cinematic landing page
- dashboard.html: command center, announcements, timer, live overview
- contestants.html: contestant management
- tasks.html: task management
- nominations.html: nominations + danger zone
- leaderboard.html: live leaderboard
- statistics.html: live house statistics

All state is shared through localStorage under key bb-house-v3.
The provided Bigg Boss eye/logo references are kept in assets/ for branding reference.

No build step is required. Internet is only used for Google Fonts; the app itself is plain HTML/CSS/JS.
